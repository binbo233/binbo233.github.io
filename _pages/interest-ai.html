01 / AI & TOOLS

把 AI 当成可以一起捣鼓的东西。

我对 AI 的各类应用都很感兴趣：AI 编程、vibe coding、AI 绘图和 AI 视频生成，都会让我产生“能不能再试一点”的冲动。最近玩得比较多的是 DeepSeek Harness 和它的各类 plugin——能自己定制一个智能体，本身就很有意思。

两个已经在运行的小插件

我给自己的 DeepSeek Harness 装了两个小插件。它们不是什么宏大的生产力系统，更像是把使用过程里注意到的小问题，做成了可以随手玩一玩的界面。

小鲸鱼挂件：把 token 消耗变成看得见的反馈

它的形象来自网友对 DeepSeek 鲸鱼形象的二创——“蓝色大肥鱼”。每段对话结束后，它会显示上一轮对话消耗的 token 费用，也会显示账户余额和当天已经使用的金额。空闲时用鼠标捏一捏小鲸鱼，还会发出解压的音效。

GitHub / DeepSeek Balance Whale Widget ↗

“滑动变祖器”：把模型等级做成一条可玩的滑块

这套界面皮肤把 DeepSeek 的推理等级做成一条滑块：从“小难梁”“牢梁”“梁子”“梁圣”到“梁祖”，每个形象对应一个等级。它的灵感来自 DeepSeek V4 发布后的网络讨论：强悍性能与开源特性让 DeepSeek 被调侃为走上“登神长阶”，宣布涨价后又一夜之间出现了“牢梁”。网友把人物形象的变化与模型等级结合起来，于是有了这个既能调参数、也能玩梗的“滑动变祖器”。

GitHub / dsh-liang-skin ↗

还在捣鼓的东西

我也在尝试自己制作一个小插件，用于实时反映模型消耗 token 的速度，以 toks/s 为单位进行可视化。它暂时没有什么“非做不可”的实际用途，更多是纯粹的自娱自乐；等完全开发好之后，会开源到 GitHub 上。
